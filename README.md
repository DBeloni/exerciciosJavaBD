# Atividades 04, 05 e 06 - Sistema de Biblioteca

Resolução da lista de exercícios de Java (POO) e PostgreSQL

## Atividade 4 - Java

A implementação demonstra abstração, herança e polimorfismo por um sistema de biblioteca que gerencia livros, revistas e usuários. O código pode ser executado em `java/src/Main.java` (tinham mais 8 commits que foram perdidos por ter que resetar o repositório)

## Atividade 5 - Modelagem SQL

Implementação do modelo de banco de dados em PostgreSQL baseado no sistema de biblioteca da atividade 4, incluindo tabelas, restrições e dados iniciais. O script pode ser executado em `sql/atividade5.sql`
